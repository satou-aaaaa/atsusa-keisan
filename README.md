# 暑さ指数けいさん（atsusa-keisan）

場所（室内・外の日かげ・外の日なた）と気温・湿度から暑さ指数（WBGT）がいくつかを当て、正解したら日常生活の指針の段階（注意・警戒・厳重警戒・危険）も選ぶ1日5問の学習ゲーム。AとBをくらべる問題では、気温が3度低いのに湿度で暑さ指数が上になる場面が出る（室内で33℃・湿度30%は25、30℃・湿度80%は28）。

遊ぶ: <https://satou-aaaaa.github.io/atsusa-keisan/>

- 室内（日差しなし）の暑さ指数は、日本生気象学会「日常生活における熱中症予防指針 Ver.4」の室内用の表 <https://www.city.bunkyo.lg.jp/documents/2725/ver4.pdf> の数をそのまま使います。
- 外の日かげ・日なたは、環境省が実況推定値・予測値に使う式（小野ら 2014。<https://www.wbgt.env.go.jp/wbgt_detail.php>）で出した目安です。風速1m/秒、日かげは日射0、日なたは日射0.9kW/m²としています。本物の暑さ指数は、照り返しや風、場所でちがいます。
- 段階とアラートの数は、環境省 熱中症予防情報サイト <https://www.wbgt.env.go.jp/wbgt.php> の日常生活・運動の指針と、熱中症警戒アラート（33）・特別警戒アラート（35）から取りました。出典はゲームの「このゲームについて」にあります。
